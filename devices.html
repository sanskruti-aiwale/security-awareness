Device hygiene

Updates, locks, encryption and backups.

Why it matters

Updates close known holes. Most attacks use flaws that already have a fix.

A lost device is a data breach. Without a lock and encryption, whoever finds it can read everything.

Backups beat ransomware. A recent offline copy lets you restore instead of pay.

Update, lock, back up.

The habits

  • Install updates. Turn on automatic updates everywhere.
  • Lock and encrypt. Use a screen lock and full-disk encryption.
  • Back up. Keep a recent copy somewhere ransomware can’t reach.
  • Install carefully. Use official app stores and trusted vendors.

Test yourself

Two options each time. Pick the better one.
