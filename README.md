# Think Before You Click — Security Awareness Site

A static, dependency-free site (one `index.html`). Hero is an interactive phishing inbox test.

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a repo and upload `index.html` (and an `assets/` folder).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Your site appears at `https://<username>.github.io/<repo>/`.

## Make it yours
Put these in `assets/`: `Security_Awareness_Training_Deck.pptx`, `report.pdf`.
Replace the YouTube link in the Materials section with your video URL.
