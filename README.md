# Think Before You Click: Security Awareness Training

A security awareness training platform designed for non-technical audiences. It shows how security concepts can be communicated clearly to the people who need them most.

**Live site:** https://sanskruti-aiwale.github.io/security-awareness/

## Overview

Security is only as strong as the people who use it. This project covers eight core topics in plain language, and each topic ends with an interactive test so the lessons stick.

## Topics

- **Phishing and email:** an inbox simulation where users classify emails, plus a fake login page challenge.
- **Passwords and MFA:** a password strength lab and a "which is safer?" test.
- **Social engineering:** phone, text and in-person tricks, with a case study of the 2023 MGM Resorts incident.
- **Device hygiene:** updates, screen locks, encryption and backups.
- **Safe browsing and Wi-Fi:** fake sites, risky downloads and public networks.
- **Data privacy:** what to share, and how to handle sensitive information.
- **AI scams and deepfakes:** cloned voices and fake video calls.
- **Incident response:** what to do, and who to tell, when something goes wrong.

## Training materials

A presentation deck is available for download on the site. A written report and video walkthrough are in progress.

## Technology

Built with plain HTML, CSS and JavaScript, with no frameworks. The password lab runs entirely in the browser, and no user data is collected or transmitted.
